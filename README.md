# gongwen-xiezuo · 公文写作技能

一个用于辅助公文写作的 Agent Skill，帮助起草、修改和把关党政机关、体制内文字材料。

## 覆盖范围
- 法定公文：通知、请示、报告、意见、函、纪要、批复、通报、决定等，含文种选择和行文规则
- 讲话类：部署动员讲话、表态发言、主持词、汇报稿、口头汇报、研讨发言、致辞、传达提纲
- 其他：总结、述职、调研报告、起草说明、简报信息、政策建议、对照检查材料
- 标题与语言规范、常用词句
- 政策研究论证工具箱、涉外法治材料专门提示
- GB/T 9704—2012 排版速查、交稿前自检清单

## 核心原则
- 不编造：数据、案例、提法拿不准时标【待补】【待核】，句子照常写完整
- 每篇稿子附起草说明：思路、假设、待补清单、需领导定夺的选项

## 使用
把 `gongwen-xiezuo/` 目录放进 Claude、codex等agent 的 skills 目录（如 `~/.claude/skills/`），或上传该技能。之后直接说“帮我写一份××请示”“改改这份汇报”即可触发。

## 来源
方法提炼自《笔杆子是怎样炼成的：公文写作实战》《笔杆子是怎样炼成的2：公文写作模板》《怎样写作》（任仲然）、《南周评论写作课》，以及《党政机关公文处理工作条例》、GB/T 9704—2012。本仓库仅含归纳整理后的方法要点，不含书籍原文，版权归原作者所有，仅供学习交流。
