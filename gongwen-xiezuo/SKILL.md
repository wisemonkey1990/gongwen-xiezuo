# 公文写作：笔杆子工作法

本技能提炼自《笔杆子是怎样炼成的：公文写作实战》《笔杆子是怎样炼成的2：公文写作模板》《怎样写作》（任仲然）和《南周评论写作课》。

**总纲**：写材料就是谋工作——把“提出问题、分析问题、解决问题”的过程，用对路的文种、规范的格式、朴实的语言写出来。好材料靠四个“研究透”：事（情况、问题、对策）、人（谁讲、谁听）、体（文种体例）、景（时机、场合）。标准是“短、实、新”，忌“长、空、假”。境界由低到高：写得像（体例对、能叙事）→写得是（布局对路、能辅政）→写得好（问题看得透、思路有新意、能推动工作）。

目录：一、底线　二、工作流程　三、法定公文　四、讲话汇报发言　五、总结述职调研等　六、标题与语言　七、论证工具箱　八、涉外法治　九、格式　十、交稿自检

## 一、底线

1. **不编造。** 数据、案例、人名职务、领导原话、文件名称和文号、会议时间、法条内容，用户没给、又无法从可靠来源核实的，一律写成【待补：……】或【待核：……】，交稿时集中列出。公文的权威来自内容真实，一处编造就会让整篇材料失信，而且审稿人很难发现。
   - **事实不能编，思路可以出。** 分析判断、工作思路、措施建议，可以依据政策常识和用户的情况提出来，供用户取舍；但不能把设想写成已经做了的事。
   - **留空不留白。** 句子照常写完整，只把具体数字、名称留空，例如“全市涉外律师达到【待补】人，较上年增长【待补】%”。这样用户填上数就能用。
2. **提法以权威原文为准。** 上级精神、政治表述、政策术语照原文引用，不凭记忆改写，不自创“升级版”。最新会议精神、领导现任职务、机构名称、法律修订状态都可能已经变化：能检索就到中国政府网、部委官网、国家法律法规数据库等权威来源核对，不能检索就标【待核】。
3. **文种和行文关系要对。** 文种一错，框架必错，内容再好也没人往下看（见第三部分）。
4. **站位要准。** 弄清以谁的名义、对谁说话，到位不越位：分管领导讲分管的事；部门不向下级党委、政府提指令性要求；代表本部门致辞，对兄弟单位只提希望、建议，不下指令。
5. **每句话都禁得住追问。** 拿不准的情况不写，看不透的现象不下断语；定性要精准，不扣大帽子，不随意上纲上线。
6. **不贪全。** “什么都说到了，什么都没有说透”是官样文章的通病。抓住最重要的问题，写深写透。

## 二、工作流程：定盘子→搭架子→敲键子→磨稿子→交稿子

### 1. 定盘子：动笔前把任务吃透

先从用户的话和所给材料里提取下列要素，能推断的直接推断：

| 要素 | 要弄清的问题 |
|---|---|
| 文种与用途 | 写什么，给谁用，印发还是口头讲，要不要上会 |
| 讲者／发文者 | 以谁的名义；一把手还是分管领导；代表单位还是个人 |
| 听者／受文者 | 上级、下级、平级、群众、专家还是外方；他们关心什么 |
| 场合与时机 | 什么会，开多长，第几个发言；年初部署、年中推进还是年终总结 |
| 核心目的 | 这篇材料要解决什么问题——必须能用一句话说清 |
| 依据 | 上级文件、会议精神、领导批示、通知要求（通知列了几条就回应几条） |
| 篇幅与时限 | 字数或时长（讲话约200～250字／分钟）、数据截止时点 |

- **关键要素（文种、讲者、听者、目的）缺失又推断不出时**，一次问清，最多问1～3个问题，尽量做成选择题。次要要素按惯例假设，并在起草说明里写明。
- **通知、函、纪要这类要素型文种**，时间、地点、人员等缺了就用【待补】占位，不为此反复追问。用户说“直接写”时，按最合理的理解写。

**吃透“四情”**，它们分别决定材料的四个维度：
- 上情：上级精神、文件、领导讲话批示。它决定高度，是材料的下限。
- 内情：本单位的历史沿革、现状、做法、数据和问题。它决定厚度和针对性。
- 下情：基层做法、群众诉求、共性问题。它决定温度和可操作性。
- 外情：兄弟地区、先进地区和国外的做法。它决定广度，是材料的上限。

向用户要材料时，优先要这几样：上级文件或会议通知；本单位以往同类定稿，尤其是领导改过、认可的版本；最新数据和进展；领导的相关讲话和批示。要材料可以和提问放在一起，但不要因为缺材料就不动笔：用户手头没有的，先写，缺口用【待补】标出。用户给了附件的，先通读全文，从中提取提法、体例和数据。

用户需要向下属单位调度材料时，可以帮他拟调度通知，写明以下要求：
- 明确数据截止时间，尽量用数据说话。
- 突出五类亮点并加黑标注：排名靠前的指标；原创性或集成性的创新做法；为民服务的成效；获上级肯定、推广或批示表扬的工作；同比大幅提升的工作。
- 下步安排突出重要政策、重大行动、重大项目和重要指标。
- 可附报近期成熟的汇报稿、总结稿。

**吃透领导意图。** 用户提供了领导讲话、批示、改过的稿子时，按下表用这些材料：

| 领导材料里的内容 | 放到哪里 |
|---|---|
| 反复说的词句 | 小标题 |
| 反复说的思路、举措 | 帽段 |
| 理念、思想 | 各部分导语 |

这样写，领导读起来会觉得“这是我的话”。意图的线索还可以从这些材料里找：领导的讲话（尤其他亲自补充修改的部分）、批示、政务信息、会议纪要、向上级汇报的材料、审定过的文件方案、发表的文章。领导改过的“花脸稿”最能说明他要什么。例行会议讲话讲究“九分惯例、一分个性”：结构仿上一次，内容写出新变化。

**找体例**，用于陌生文种或陌生题材，能检索就检索：
- 原则是“高层级找体例，相近层级找框架”。到中国政府网、部委网站、省级政府网站找5～10篇同类范文，检索式如“关键词 site:gov.cn”。层级越高越规范；同层级范文的框架最可借鉴。
- 借鉴时形神兼顾：学体例，更学逻辑。
- 多篇比较、集各家之长，不照搬一篇。外地的学思路，本单位的守惯例。
- 文风与层级匹配：县乡材料不照搬省部级文风，不搞“上下一般粗”，要更朴实具体。
- 逐字校对，绝不能把别人的地名、单位名带进来。

### 2. 搭架子：先有提纲，再有全文

“画竹必先成竹于胸。”搭框架就是想清楚“怎么写”：每列一条，下面分几层、说什么、说到什么程度、用哪些事实，都应清楚。

**公文的核心逻辑是“是什么—为什么—怎么办”**，也就是提出问题、分析问题、解决问题。全篇、每一部分乃至每一段，都可以沿这条链展开。受众熟悉的工作少讲“为什么”，多讲进展和打算；新部署的工作三者都要讲到位。各文种的主干逻辑如下：
- 部署讲话：为什么干（意义、形势、紧迫性）→干什么（重点任务）→怎么干（方法、责任、保障）
- 总结、报告：做了什么、成效如何→存在问题→下步打算
- 汇报：按听者需要排序，他关心什么先说什么（见第四部分）
- 请示：为什么请示→请示什么事项→请求批准，并附倾向性意见
- 意见、方案：总体要求（指导思想、原则、目标）→重点任务→保障措施
- 调研报告：基本情况→问题→原因→对策建议
- 对照检查：问题→思想根源→整改措施，层层递进、一一对应

**贯彻上级部署的材料**，把上级要求放进帽段，作为总靶向；再掰成关键词，放进小标题。既不大段照抄上级，也不另起炉灶：要把上级讲话和上级方案的逻辑融为一体，再补上本地特色，留出结合实际的空间。

**提纲的硬要求**：
- 一个主题统领全文，主线只有一条。大标题凝练主题，小标题分解主题；写偏了，对照标题拉回来。
- 越往上一级标题越要有高度，越往下一级越要有实度。
- 标题层级随篇幅定：
  - 一般两到三级。
  - 4000字左右的讲话设到二、三级，七八千字的设到三、四级。
  - “我只讲三件事”式的短讲话，一级标题就够。
- 并列各项要满足三点：同一“辈分”（爷爷辈和孙子辈不能并列）；概念不交叉；比重大体相当（不能一块1500字、一块150字）。
- 不硬套“情况—原因—措施”三大块：有几条写几条，问题和原因可以合写，工作按内在逻辑排列。
- 每部分的最后一点可兼作向下一部分的过渡，避免生硬的“过渡装置”。
- 三、四级标题不必过早雕琢。全文写成后，再从实质内容中提炼，“打到哪儿指到哪儿”。

**先报提纲**：
- 长篇或重要材料（讲话、报告、方案等）关键意图还不确定时，先交不超过一页纸的提纲请用户确认，再写全文。提纲早出手、初稿晚出手，可以少走弯路。
- 请领导定框架时，给“选择题”（两三个方案加倾向性意见），不给“填空题”。
- 用户已明确要全文时，直接写全文。

**示例：动员讲话提纲**（一级标题讲大局，二级标题落实处）
> 一、提高政治站位，深刻认识开展××工作的重要性紧迫性
> （一）这是贯彻落实……的政治要求　（二）这是推动……的现实需要　（三）这是解决……突出问题的迫切需要
> 二、聚焦重点任务，确保××工作取得实效
> （一）坚持“严”字当头，着力解决……问题　（二）坚持“实”字托底，着力解决……问题　（三）……
> 三、强化组织保障，推动各项任务落地见效
> （一）压实责任　（二）强化督导　（三）营造氛围

### 3. 敲键子：起草

- **问题往深处想，事情往实里写。** 立意可以高，但要脚踏实地再落笔。
- **开门见山，结论先行。** 帽段亮明依据、目的或总判断；各部分先给结论（标题加导语），再用事实、数据支撑。以上统下，归类分组，逻辑有序。公文不玩悬念。
- **用观点统率材料。** “只谈情况、不谈观点，是开材料仓库。”反过来，只有观点、没有材料，就干瘪空洞。每个判断都要有事实或数据垫底，每段材料都要服务于一个观点。
- **写好导语句。** 小标题容易同质化，材料的个性靠各部分、各段开头的导语体现。导语从三处提炼：该部分最大的亮点、领导最关注的点、服务对象最关心的点。做到文、导、题一致。
- **“摞”材料，再“归堆”。**
  - 先把可用素材按提纲摞到末级标题下，比对筛选。
  - 再合并同类项：从属关系的删减压缩；并列关系的合并，或用顿号压缩；一律向主题聚拢。
  - 在信息量上做加法，在文字上做减法。
- **稿中有数。**
  - 能量化的都量化。数据要讲清时点和口径，并有对比（同比、环比、排名、占比、“首次”“突破”）。
  - 能精确统计的写细数，不易统计的用百分比。
  - 数据为定性判断服务，不堆成报表，更不能注水。
- **事例写透。** 轻描淡写八九个一般情况，不如浓墨重彩写透三四个典型事例。事例要有普遍性，不用孤例证明普遍问题。
- **措施可操作。** 部署性内容要回答四个问题：谁来干、干什么、干到什么程度、什么时候完成。可量化的写指标；时限写到日（领导说“6月底”，文件写“6月30日前”）；责任单位括注在任务后。部署时“一个句号就是一项要求”。
- **政策要衔接。** 新提的措施不能与现行政策、上位规定“打架”。日常事务、临时工作，不要轻易写成政策规定。
- **先完成，再完美。** 起草能快则快，一气呵成；修改能慢则慢。不要对着“毛坯”吹毛求疵。

### 4. 磨稿子：修改与自检

“好文章是改出来的”，修改至少要花一半功夫。改的顺序是先大后小：
1. **立意和主题**：基调、中心思想和主要判断对不对，有没有力度。删掉跑题的“岔路”，补强薄弱处。
2. **结构**：
   - 先查四个问题：四梁八柱正不正；架子是不是拉大了；是不是“小马拉大车”；层级是不是拆得过细。
   - 框架装不下内容时，就动结构的大手术：并列改递进，三大块拆成五六条，松散改紧凑。
   - 篇幅减不下去时，在结构上做减法，比删几个字有效得多。
3. **事实和事例**：逐一核对。把所有事例放在一起看，剔除雷同的、游离主题的、彼此不协调的。
4. **段落和语句**：理顺前后衔接，从前往后、从后往前各理一遍。
5. **字词和标点**：最后逐字推敲。一个标点可能改变一个判断，一个错别字可能拖累整篇。

**四审**（交稿前必过）：
- 审任务：通知要求和领导交代的要素，是否都回应了？时间跨度、数据口径对不对？
- 审意图：领导反复强调的工作，是否放在了突出位置？风格是否与领导认可的定稿一致？意图体现不充分，返工几乎是必然的。
- 审框架：文题是否一致？文导是否一致？素材撑不撑得起标题？
- 审亮点：有没有“别无我有、好使管用”的举措或判断？先问能不能打动自己。

**审核把关**（替领导或办公室审别人的稿子时），按《党政机关公文处理工作条例》的审核重点逐项过：
- 行文理由是否充分，依据是否准确。
- 内容是否符合政策法规，是否体现发文机关意图，是否与现行公文衔接，措施是否可行。
- 涉及其他地区、部门职权的，是否已经协商一致。
- 文种是否正确，格式是否规范。
- 人名、地名、时间、数字、段落顺序、引文是否准确。
- 文字、数字、计量单位和标点用法是否规范。

**常见毛病对照改**（何其芳归纳的十二种毛病，结合公文实际）：

| 毛病 | 改法 |
|---|---|
| 抽象笼统，叙事不具体，说理不充分 | 实化细化，补事实、补因果 |
| 根据不足就下断语 | 改成写实，或者删去 |
| 强调一点不加限制，容易走极端 | 补上限定，把过头话改得恰如其分 |
| 大家都知道的事说得很多 | 删去，或换个角度 |
| 别人不知道的事说得很少 | 补充受众想知道的新情况、新做法 |
| 许多事情随便堆在一起，读完一片模糊 | 重新确立中心，按中心取舍、重排结构 |
| 写到下句不管上句，写到后面不管前面 | 回头看，前后照应 |
| 离题万里又舍不得删 | 忍痛割爱，“精彩之笔”也要服从主题 |
| 抄书太多 | 删去抄来的，补上自己的 |
| 生造词语，乱用术语，疙里疙瘩 | 换成准确通行的说法；先分清是“理屈”还是“词穷” |
| 啰唆重复，马虎破碎 | 合并同类，一个意思只说一遍 |
| 学翻译腔造长句，一逗到底 | 拆成短句，把复杂句改成简单句 |

**删、换、写、顺**：
- 删：与标题不挨边的金句；出处不明的；有歧义的；还要再解释的；数据缺乏支撑的；明显不符合实际的。
- 换：舍不得删的，挪个位置，或者改写到与上下文相容。
- 写：补写开头、结尾和导语。
- 顺：理顺事与事、段与段之间的衔接。

多人分写的稿子要统稿，统一思路、体例、风格和提法，防止畸轻畸重。重要讲话和政策文件默改几遍之后，再“念改”：读出声来，拗口、歧义、断气的地方一听便知。改到没什么可改、甚至把改过的词句又改回来的时候，就可以定稿了。

### 5. 交稿子

在对话中直接给出正文时，按公文习惯排：层次用“一、”“（一）”“1.”“（1）”编号，不用 Markdown 标题符号、项目符号或加粗，方便用户直接粘贴进 Word。放进文档或 Word 文件时，按第九部分的格式排版。

正文之后，用分隔线隔开，附三五行**起草说明**，方便用户直接复制正文，也方便审稿。起草说明写四项：
- 起草思路：依据什么，围绕什么问题，怎样谋篇。
- 所做假设：讲者身份、场合、篇幅等。
- 【待补】【待核】清单：需要用户补充或核实的数据、事实和提法。
- 需要领导定夺的选项：例如两种标题、两种表述。

示例：
> 起草说明：①依据××通知要求，按“成效—问题—建议”起草，建议部分对应通知第三条；②按15分钟讲话（约3500字）把握篇幅；③待补：1—9月××数据、××典型案例；待核：××提法以最新文件为准；④第三部分建议给出A、B两种表述，请定夺。

修改别人或用户的稿子时：
- 先给修改稿，再按重要性列出主要改动和理由，不罗列错别字。
- 尊重原稿：不需要改的不硬改，该改的改到位。
- 原稿如果没有立意、主线和逻辑，润色字句就没有价值。这时直说问题，给出重构提纲，或列出需要补充的材料。

## 三、法定公文（依《党政机关公文处理工作条例》）

### 文种选择

| 文种 | 什么时候用 | 要点 |
|---|---|---|
| 请示 | 向上级请求指示、批准 | 事前行文，一文一事，必须有结语，上级必须批复 |
| 报告 | 向上级汇报工作、反映情况、回复询问 | 事前、事中、事后均可，上级可不答复；**报告里不得夹带请示事项** |
| 函 | 不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批 | 如向平级主管部门申请审批 |
| 通知 | 发布、传达要求下级执行或有关单位周知的事项；批转、转发公文 | 最常用 |
| 通报 | 表彰先进、批评错误、传达重要精神、告知重要情况 | |
| 通告 | 在一定范围内公布应当遵守或周知的事项 | |
| 公告 | 向国内外宣布重要事项或法定事项 | 也常用于向社会公开征求意见：写明反馈渠道、截止时间，并说明信息仅用于汇总 |
| 公报 | 公布重要决定或重大事项 | 多为会议公报：“会议充分肯定……会议认为……会议强调……” |
| 意见 | 对重要问题提出见解和处理办法 | 上行、下行、平行均可 |
| 决议 | 会议讨论通过的重大决策事项 | 必须经会议表决通过 |
| 决定 | 重要事项的决策部署、奖惩，变更或撤销下级不当决定 | 可由机关依职权作出，不必经会议通过 |
| 命令（令） | 公布法规规章、宣布重大强制措施、嘉奖 | 奖惩力度：命令＞决定＞通报；命令只奖不惩 |
| 纪要 | 记载会议主要情况和议定事项 | 不是会议记录，也不是会议简报 |
| 批复 | 答复下级请示 | 一请示一批复，只发给来文机关 |
| 议案 | 各级政府按法律程序向同级人大或其常委会提请审议事项 | |

撤销和废止效力不同：撤销自始无效，废止自废止之日起失效。

### 行文规则要点
- 一般不越级行文；确需越级的，同时抄送被越过的机关。
- 上行文原则上只主送一个上级机关，不抄送下级。除上级负责人直接交办的事项外，不以本机关名义向上级负责人个人报送公文。
- 部门向上级主管部门请示、报告重大事项，须经本级党委、政府同意或授权。
- 转报下级的请示，须提出倾向性意见，不得原文转报。
- 部门不得向下级党委、政府发指令性公文。
- 涉及多个部门职权的事项，部门之间未协商一致的，不得向下行文。
- 属于党委、政府各自职权范围内的工作，不得联合行文。
- 部门内设机构（办公厅、室除外）不得对外正式行文。
- 起草要求：
  - 符合方针政策和法律法规，准确体现发文机关意图，并同现行公文相衔接。
  - 措施切实可行。
  - 做到“内容简洁、主题突出、观点鲜明、结构严谨、表述准确、文字精练”。
  - 涉及其他地区、部门职权的，须征求意见，力求一致。
- 涉及外事的公文，依照外事主管部门的有关规定处理。

### 常用文种骨架
“××”表示待填内容。

**请示**
- 三原则：一文一事、一文送一头（只主送一个上级机关）、一文一语气。
- 骨架：“关于××的请示”→主送一个上级机关→缘由（“根据……”“为……”，讲清依据和必要性，理由要真诚具体）→事项（具体、可操作；有几种方案的都列出，并提出倾向性意见）→结语。
- 结语用“妥否，请批示。”“当否，请批示。”或“以上请示，请予批复。”
- 请示是上行文，版头要标注签发人；按惯例在成文日期下附注联系人和电话。
- 会议类：“拟于×月×日召开××会议，现就有关事项请示如下：一、会议名称 二、时间（具体根据××同志安排确定） 三、地点 四、参会人员（约×人） 五、议程（请××主持，请××讲话） 六、筹备分工。当否，请批示。”
- 资金类：起因→必要性和依据→测算（列明口径）→自身无力承担的说明→请求金额。
- 机构类：设立的必要性→组织架构→主要职能→人员编制来源。

**报告**
- 骨架：“关于××情况的报告”→帽段（结尾句：“现将……情况报告如下：”）→一、基本情况，或主要做法及成效；二、存在问题；三、下一步打算或建议→“特此报告。”
- 讲清来龙去脉，不要以为自己知道的上级也知道。
- 必须报告的事项：本地重大事件、重要工作进展、上级批示的办理情况、文件明确要求报告的事项（按时限报）。
- 报喜也报忧。焦点难点问题、倾向性和深层次问题最有价值。
- 问题性报告五要点：
  1. 靠扎实调查，不靠二手材料。
  2. 先辨是不是真问题，再判属性：是体制问题，还是管理问题。
  3. 写透三四个典型事例。
  4. 定性精准，大小标题就是判断，不扣帽子。
  5. 一定提出解决办法，不“矛盾上缴”。

  标准是：今天写的报告，几个月、几年后仍然无懈可击。

**通知**
- 部署性通知：
  - 骨架：首段写依据和目的（“为……，经××同意，现就……通知如下：”）→一、二、三分条提要求→结尾“特此通知”，或写具体落实要求（“贯彻落实情况于×月×日前报××”）。
  - 重点告诉下级：什么不能做，什么应该做，怎样做，做到什么程度。
  - 意义和认识少写或不写；要求要量化、具体。
- 会议通知：
  - 骨架：“为……，经研究，决定召开××会议。现就有关事项通知如下：一、会议时间（含报到时间） 二、会议地点或方式（主会场、分会场、视频） 三、参会人员 四、会议议程 五、有关要求（回执、发言时长和材料报送、着装、请假、视频联调、会议纪律等）”→联系人和电话→附件回执。
  - 原则是一目了然、不易误解。会标、议程、桌签这类内容出错难以纠正，要格外细心。
- 印发通知：
  - 写法：“现将《××》印发给你们，请结合实际认真贯彻执行。”
  - 印发总结类材料用“认真学习领会”，不用“贯彻落实”。
  - 不相关的文件不打捆印发。

**意见、实施意见、方案**
- 推荐体例是拉条式（改进文风），同时遵循领导意见和本机关同类文件的惯例：
  1. 帽段：交代背景和必要性，或开门见山，接“为……，经××同意，现提出如下意见：”。
  2. 一、总体要求：指导思想、工作原则、主要目标。目标尽量用数据和时间节点。
  3. 二、重点任务：逐条列出，每条后括注责任单位。
  4. 三、保障措施：组织领导、资金保障、法治保障、督查考核、宣传引导。
  5. 最后写施行日期，以及与原有规定的关系。
- 常用原则：坚持问题导向、目标导向；坚持系统观念；坚持依法行政；坚持因地制宜、分类施策；坚持试点先行、示范推广。
- 起草前先回答三个问题：
  1. 这个文件到底要解决什么问题？
  2. 上级各层级是怎么要求的？
  3. 干货措施从哪里来？有三个来源：比较同类政策（检索多个省市的同类文件，标出可借鉴处）；与服务对象座谈，弄清他们要什么；与相关部门座谈，弄清能给什么、给到什么程度。
- 专项意见不铺垫、不议论，一步入题。综合意见可以先写认识，但不能写成论述文章。一般规定与特殊规定相结合，原则性与灵活性相统一，不搞一刀切。
- 责任括注的写法有“（××牵头，××、××等按职责分工负责）”“（××负责）”“（各地区各部门按职责分工负责）”等。括注内容须在征求意见阶段与责任单位达成一致。
- 法治保障的常用表述：“涉及突破现行法律法规规章和规范性文件规定的，按程序报批，取得授权后施行”“做好与相关法律法规立改废释的衔接”。
- 方案是“时间表＋路线图”：规定动作要做到位，自选动作要结合实际。
- 其他方案：
  - 会议筹备方案：主题、时间、地点、人员、议程（每项时长）、分工、筹备进度。
  - 接待方案：日程精确到时分，按规定从简。
  - 调研方案：内容、分组、行程、成果节点。

**函**
- 征求意见函：
  - 写法：“为……，我×起草了《××（征求意见稿）》，现送你单位征求意见。请于×月×日前书面反馈意见（逾期未反馈的视为无意见）。”
  - 给对方留足研究时间。
- 复函：
  - 开头写“你单位《××（征求意见稿）》收悉。”用“收悉”，不用“已收悉”。
  - 无意见：“经研究，我×无修改意见。特此复函。”
  - 有意见：逐条写“建议将第×条第×款中‘……’修改为‘……’。理由：……”
- 语气平等商洽：不卑不亢，不写客套空话，也不用命令口吻。需要回复的，结语用“请予函复”；不需要回复的，用“特此函告”。
- 邀请函：称谓用全称或职务；时间、地点、事项写周全；语气诚挚，结语如“敬请拨冗出席”。

**纪要**
- 骨架：“××会议纪要”→帽段→按议题分段→“会议还研究了其他事项。”→出席、列席、请假人员。
- 帽段写法：“×年×月×日，××在××主持召开××会议，研究……。现纪要如下：”。专题会议的首句要写明授权，如“根据××会议精神，……”。
- 每个议题的写法：“会议听取了……汇报。会议原则同意……，由××根据会议意见修改完善后按程序印发。会议强调……会议要求……”
- 重点是议定事项：逐项列出、可操作；时间节点写到日；责任单位括注在事项后。责任分工是纪要的“兜底条款”，缺了它，议定事项就很可能落不了地。
- 综合性会议纪要要详略有别，该归堆的归堆。纪要不写成记录，也不写成简报。

**批复**
- 写法：“你单位《关于……的请示》收悉。经研究，现批复如下：一、同意（或原则同意）……二、……三、……（要求）特此批复。”
- 不同意时委婉表达，如“暂缓”“待条件成熟后再……”。

**通报**
- 表扬：写事迹及意义→“为……，经研究，决定对……予以通报表扬”→对受表扬者提希望→号召学习。
- 批评或事故：写总体情况→逐起列事实（时间、地点、经过、后果）→暴露的问题（“充分暴露出……一是……”）→处理结果→提要求（举一反三、建立问题清单、闭环管理）。

**决定**
- 骨架：缘由（背景、目的、依据）→决定事项→执行要求→施行时间。语言以说明为主，准确严密，不模棱两可。
- 修改类决定写成：“一、将第×条修改为：……二、增加一条……三、删去……”

## 四、讲话、汇报、发言

### 共性要求
- **三个吃透**：
  - 吃透真实情况，这是基础，再小的会也要先摸情况。
  - 吃透上级精神，这是关键。要逐级吃透；转述时“上接天线、下接地气”，不大段照搬。
  - 吃透领导意图，这是直接依据。从领导以往讲话、批示中揣摩，不能猜着写。代上级领导起草时，先把他近期的讲话和政务活动报道通读一遍，找到“站在他的位置上说话”的感觉。
- **对象意识**：
  - 同样的内容，对机关干部、基层群众、专家要讲得不同；一把手和副职讲法也不同。
  - 汇报稿研究听者，比研究讲者更重要。
  - 对地方党委、政府汇报，讲深入浅出的大白话；对上级行业部门汇报，“半白半行”，不和上级比专业。
- **思想性、针对性、指导性**，三者中指导性最重要。还要追求五个“度”：
  - 实度：七分实，二三分文。
  - 深度：要“挖深井”，不要“编大筐”。
  - 高度：要有制高点，也要有支撑点。
  - 新鲜度：不今年抄去年、下级抄上级、现任抄前任。
  - 气势：要有，但不盛气凌人。
- **选小切口，展大思路**：从一个具体现象、一个真实故事切入，由小到大，把大道理讲进人心里。
- **讲稿要上口**：
  - 句子长短相间，适度口语化，可以用设问、反问。
  - 不用生僻字词；把握不大、不太准确的话不讲。
  - 概括几个易懂好记、便于传达的词句——一篇讲话能让与会者记住一句话、几个词，就成功了。
- **宜短不宜长**：
  - 应急讲话、专项部署讲话、即席讲话、内容单一的讲话，都要短。
  - 即席讲话以15分钟左右为宜，一般会议讲话25分钟左右；年度会议的主报告最好不超过两小时。
  - 可讲可不讲的，不讲。
- **跳出业务看业务**：讲生产力不忘生产关系，讲业务工作不失政治考量。

### 部署动员讲话
- 骨架：
  1. 标题“在××会议上的讲话”，署职务、姓名、日期；称谓“同志们：”。
  2. 帽段：说明会议任务，简评前面的发言，接“下面，我讲几点意见。”
  3. 一、提高站位，统一思想（为什么干）：正面讲意义，反面讲不干的危害，结合时限讲紧迫性。常从上级精神、全局工作、本单位职责三个层面讲。
  4. 二、正视问题（可省略）。
  5. 三、突出重点（干什么）：抓重点难点，不求面面俱到；细节交给方案。
  6. 四、强化保障（怎么干）：组织领导、压实责任、督查问效、宣传引导。
  7. 结尾：简短有力，加油鼓劲。
- 年度工作会议讲话：
  - 上年成绩高度浓缩，几个短标题加“得益于……”即可。
  - 成绩按上年部署的工作主线来提炼，前后呼应。
  - 形势分析重在研判困难和应对之策，不渲染畏难情绪。
  - 收尾前可用“最后，再强调一下……”，从微观角度提醒当前紧要工作。
  - 结尾常落在五处：看齐意识（“在……坚强领导下”）、旗帜方向（“以……为指导”）、精神状态、目标任务、重大节点。具体提法以最新权威表述为准。

### 表态发言（3～10分钟，800～2000字）
- 骨架：主副标题（主标题直接亮态度或目标）→称谓→简短背景→表明坚决态度→“具体表态如下：一是……二是……三是……”（落实举措要明确具体、务实管用）→再次表态。一级标题就够。
- 核心是表态度、亮措施，不是介绍经验，更不是部署工作。只拍胸脯、没有措施，就显得空。

### 主持词
- 骨架：“现在开会”→说明会议由来和任务→介绍参会人员→“会议议程有×项”→逐项串联→领导讲话后简要评价→提几点落实要求→“散会”。
- 领导讲话后的评价要恰如其分，不过度追捧。落实要求围绕传达、落实、督查来提，贵在新、实、短。
- 主持词要简约而不简单，不能喧宾夺主。

### 汇报稿（书面汇报、会议汇报）
- 汇报稿的建议部分，往往就是决策的初稿。汇报有理有据，决策就水到渠成。
- **按“需”汇报，不按“有”汇报。**
  - 听汇报的领导是带着问题来的：干了没有，干了什么，效果怎样，有什么问题，需要他支持什么。
  - 通知列了几条要素，就写几条；即使要创新发挥，这些要素也必须完整呈现。
  - 领导最关心的、干得最好的，先说、多说。
- 常用结构：基本情况（含亮点）→存在问题→下一步思路和建议。会议交流时，可以逐项写“问题＋对策”。
- 写问题、措施和建议的分寸：
  - 问题定性要准确，不夸大，例如“苗头性的，不是决定性的”。
  - 措施针对问题写，顺势带出成效。
  - 建议站在全局提、有实践支撑，才容易被采纳；需要争取支持的，把困难和诉求写具体。
- 多人同场汇报时，找准自己的切入点，避免“撞衫”。向多位领导汇报时，兼顾各自分管领域，可以用“主报告＋专项附件”的形式。
- 开头可以简介基本情况。典型经验要写成可复制、可推广的。介绍情况“有长不掩长，有短不护短”，不露“王婆卖瓜”之气。
- 常用起止语：开头“按照……安排，现将……情况汇报如下”；结尾“以上汇报，不妥之处请批评指正”。

### 口头汇报（当面向领导汇报）
- 先问时间：“××，关于……，想占用您×分钟汇报一下，您看方便吗？”
- 先亮结论或建议：“关于××，我建议……”
- 再讲理由，一二三，用事实说话。
- 最后把决定留给领导：“您看可以吗？”

### 学习研讨、交流发言
- 骨架：开头真诚呼应会议或辅导（“听了……，很受启发，谈三点体会”）→每点体会写三层：理论认识，联系本人和本单位实际剖析问题，今后打算→结尾。
- 要有理论高度，又要紧密联系思想实际和工作实际。可以引用辅导报告的观点，既表示尊重，又紧扣主题。
- 听众水平相当时，出彩靠“见人所未见、发人所未发”：切入准，结构清（主题前置，不层层嵌套），思考深。
- 听报告后的讨论发言：总体感受→评价报告（总体评价，以及对成效、经验、问题、部署的评价）→本地做法→落实打算。

### 座谈会发言、征求意见发言
- 立足本部门职能，站在所代表的一方说话。
- 对政策条文提意见，要具体到条款，并说明理由。
- 专题座谈会发言：先写明突出问题，再讲做法、措施和成效，最后提炼经验性认识。

### 致辞
- 骨架：
  1. 称谓和问候。可用应时应景的对仗句，结合时令、地域、历史人文。
  2. 活动意义。
  3. “我谨代表……向……表示热烈欢迎、衷心感谢”。
  4. 简介本地、本单位情况或活动沿革。
  5. 提希望、建议或倡议：对下级和服务对象用“希望”，对兄弟单位用“建议”“倡议”，或直陈观点。
  6. 诚邀合作，致以祝愿，“谢谢大家！”
- 下笔前先逐字研读活动方案，弄清背景、主题、流程和嘉宾。想清楚三件事：听众是谁，我们需要他们做什么，我们能为他们提供什么。
- 可以搜几篇同类致辞，把握体例和篇幅。
- 加入与受众互动的话（请教、承诺、邀约），避免“台上尬聊，台下懵圈”。

### 传达提纲
- 骨架：会议概况→主要精神（“会议指出……强调……要求……”）→贯彻落实打算。
- 处理原讲话：“留”核心观点和部署要求；“删”阐述性语言；“变”——不照搬原讲话的标题，按核心要求重新概括。

### 任职表态、离任感言
- 任职表态：感谢组织信任→深感使命光荣、责任重大→从政治、学习、实干、为民、团结、廉洁几方面表态。在人大任职时，要写“自觉接受人大及其常委会的监督”。
- 离任感言：拥护组织决定→感谢、不舍→欣慰（成绩归功于组织和大家）→祝福。

### 贺信、慰问信、感谢信
- 贺信（贺电）：开篇表示祝贺→恰如其分地评价，不过火→提希望或致祝福。
- 慰问信：节日慰问写时令→“值此……之际，谨代表……致以慰问”→评价过去→提希望→致祝福。灾害慰问先表示慰问，再写援助安排。
- 感谢信：感谢事由→致谢→希望继续合作→祝福。

## 五、总结、述职、调研报告等

### 工作总结
- 骨架：帽段（“××年，××以……为指导，紧紧围绕……，……取得明显成效。”）→分项写成绩和做法→存在问题→下步打算。也可以先列主要成绩（短标题加数据），再写主要做法。
- 帽段出彩有四法：
  - 量：办件量、金额、项目数。
  - 质：领导的肯定性批示、全国第一、获评优秀、经验被推广。
  - 重大事件：承办全国现场会、获批国家试点。
  - 对比：同比增长、排名提升、高于全国或全省平均。
- 选大事要事，不写流水账。要发现以前没有的新事，总结以前没总结出的经验。
- 同一份基础稿，按用途“看人下菜”：
  - 给上级综合材料提供素材：重概括、重亮点。
  - 供领导决策参考：问题不怕“家丑外扬”，越具体越好。
  - 报上级业务部门：情况兜清，问题写深，措施写细。
  - 用于交流发言：多讲可复制、可推广的做法。
- 报告、汇报、总结的区别：报告端庄专业，汇报灵活通俗，总结一般是“成绩—问题—打算”三段。三者有共同的“三喜三忌”：喜提炼概括，忌流水账；喜吃透四情，忌抄袭敷衍；喜聚焦实际问题，忌拍脑门空谈。
- 格式上，总结一般不写主送机关，也不落款。

### 工作要点
- 骨架：背景（“××年是……之年”）→总体要求和目标→分条列出要点。
- 要点要重点突出、可操作。不写主送，不落款。句式避免通篇都是“要……”。

### 述职报告
- 骨架：标题→称谓→任职和职责（“按照……要求，现将本人履职情况报告如下，请予评议”）→总体评价→分项（理论学习、履职尽责、抓班子带队伍、廉洁自律）→存在问题→努力方向→“以上述职，请予评议。”
- **紧盯“我”**：述职报告不是单位工作总结，要写清本人的位置、作用和亲自做的事。不贪他人之功，成绩不写满、作用不写过头——团队成员心里都有一本账。
- **以实取胜**：写有全局价值的“大实”，不列事务清单式的“小实”。理论学习要写怎样联系实际、指导工作，不能只写学了什么。
- **以数取胜**：工作量、成效、职务行为都可以量化，如下乡多少天、跑了多少个县、讲话多长、文件减少多少。数据要与职务直接相关，为定性服务。
- **以事取胜**：一件一件写清根据什么干、怎么干、成效如何。重点写自己发挥主导作用的大事要事。
- **问题不能缺**：找准说透，不蜻蜓点水，也不夸大。只谈成绩、不谈问题是硬伤。德、能、勤、绩、廉尽量写全。

### 调研报告
- **好报告是调查研究出来的，不是写出来的。** “七分调研、二分思考、一分报告。”
  - 真：是底线。
  - 实：情况实、问题实、建议实。
  - 深：挖到问题的根子。
  - 高：站位高、视野宽。
  - 在这四条的基础上，再求新、求活。
- **边调研边起草**：调研提纲就是报告提纲的“影子”；白天调研、晚上成稿，不搞“两张皮”。材料“博观约取”，了解到三四十个情况，能用上十来个就不错。
- **按任务选结构**：
  1. 工作类：调研概况→基本情况→主要做法→存在问题→（启示）→意见建议。
  2. 问题类：问题表现→原因及危害→对策措施。每个标题就是一个问题，每条建议都对着问题。
  3. 经验类：做法→成效→启示→建议。调子不能过高；经验都有适用条件，不搞“放之四海而皆准”。
  4. 研究类（政策、法规、对策研究）：立论求新、求深、求专，不说外行话。提政策建议，要论证必要性、可行性，以及需要防范的偏差。
- **标题**：
  - 可用常规式（“关于××的调研报告”）、判断式、设问式或正副标题式。
  - 最好的标题本身就是结论，如“母猪也应该下放给农民私养”。
- **帽段**写清调研时间、对象、范围、方式和总判断。
- **观点要鲜明精确**：
  - 可以先摆事实和数据，到呼之欲出时点出结论（画龙点睛）。
  - 也可以先亮观点，再层层论证（先画靶心）。
  - 结论要表达机关的看法和主张，不含糊其词。
  - 拿不准的情况不写，看不透的现象不写。
- **结构极简**：一条主线，能简则简。

### 起草说明（政策文件、重要报告）
- 骨架：
  1. 起草背景和必要性。
  2. 起草过程：领导重视、成立专班、调研论证、征求意见。征求意见情况写成：“共征求×个单位意见，收到×条，采纳×条，部分采纳×条，未采纳×条，主要原因是……”
  3. 制定依据。
  4. 主要内容：“共×部分×条，主要……”
  5. 需要说明的问题。
  6. 结尾：“特此说明”，或“以上说明，连同××，请予审议”。
- 其中“主要内容”和“起草过程”必须有，其余几项可以合并。

### 简报、信息
- 四字要求：
  - 简：一般不超过2000字。
  - 亮：在标题上下苦功夫。
  - 实：数据和事例精准。
  - 新：内容新，报送快。
- 标题多用“措施＋成果”，也可以：
  - 用数字概括，如“三个坚持”“‘123’工作法”。
  - 用单字概括，如“念好‘稳、进、新’三字诀”。
  - 用对比，如“变……为……”。
- 开头就给结论。转发类简报加编者按。
- 向上报送政务信息：先研究拟投载体已刊发的同类信息，照它的体例和篇幅写。一事一报，标题就是核心事实或做法；首段讲清在什么背景下、做了什么、成效如何；数据和事例要具体。

### 政策建议、专报
- 写给决策者看，结论先行：标题就是核心判断或建议，导语用两三句话概括“什么问题、多严重、建议怎么办”。
- 骨架：问题或情况（用数据和典型事例说清）→原因和影响分析（分清直接原因与深层原因）→对策建议。
- 建议要具体、可操作：写明谁来做、做什么，可以分近期和中长期。论证必要性和可行性，说明需要防范的风险；涉及法律政策调整的，写明依据和程序。
- 篇幅宁短勿长。复杂材料用“主报告＋附件”处理，正文只留判断和建议所必需的内容。

### 对照检查（检视问题）材料
- **结构**：问题→原因→整改措施，层层递进。原因要从世界观、人生观、价值观等思想深处挖。问题是贯穿全文的主线，整改措施与问题一一对应。
- **问题要准确具体**：
  - 分类科学：形式主义的问题，不放到官僚主义下面。
  - 每条落到一件具体事或一个具体表现。
  - 与班子查摆的问题对号入座，该认领的认领。
  - 持续整改的问题，要写出新的表现。
- **三个坚持**：
  - 坚持问题导向：优点、成绩不写。
  - 坚持高标准对照：往高处看。
  - 坚持实事求是：不推卸，不避重就轻，不言过其实。
- **语言朴实**：
  - 少用“不够”“不足”“不深”“进一步”“更加”。
  - 不说一句问题又“兜”一句成绩。
  - 思想认识夹叙夹议，深刻而实在，不写成学习体会文章。

## 六、标题与语言

### 标题
- 好标题的标准：概括得全，表述得准，叫得响，传得开。领导反复说的词、通知强调的要求、本单位独有的亮点，优先放进标题。
- 常用句式：
  - 成效型：“业务名称＋成效词”，如“营商环境明显改善”“产业结构更趋优化”。
  - 措施型：“领起词＋做法”，如“着力……”“聚焦……”“坚持……”“扎实推进……”“在……上下功夫”。可以加状语和成效，如“聚焦××，着力××，××更加有力”。
  - 组合型：
    - 做法＋成效：“扎实推进污染防治，生态建设见到新成效”。
    - 理念＋做法。
    - 四字方法＋成效：“多措并举，新旧动能加快转换”。
    - 七字句：“敢为人先抓发展，居安思危促转型”。
- 同级标题用统一的领起词或字词串联，句式对称、字数相近。但形式服务内容，不为对仗牺牲准确。
- 汇报和简报的标题可以生动一些：比喻（当好“店小二”、抓住“牛鼻子”）、数字（“一个中心、两个支撑”）、对比（“变被动应对为主动作为”）。
- 正副标题：正题表态度、亮观点，副题交代事项或场合。

### 语言
- **朴实**：
  - 少用修饰语，不用生僻词，不绕圈子，不追辞藻，不硬凑四六句，不搞文字游戏。
  - 去掉空话、套话、废话。
  - “公文不是论文，多用写实的笔法，少用议论的笔法。”
- **简练**：
  - 多用短句，段落不宜过长，核心句放在段首。
  - 一个意思只说一遍；能删的字、句、段都删。
- **准确**：
  - 概念前后一致，褒贬得当。
  - 成语典故用对：例如“殷鉴”指失败的教训，不能当“借鉴”用。
  - 引文和出处都要核实，引用之后要引申到本单位实际。
- **有分寸**：
  - 判断有依据；程度词要有限定，如“一些”“部分”“总体上”。
  - 下级对上级尊重而不谦卑，上级对下级明确而不训斥。
  - 公文提要求要斩钉截铁，不用商量口气（便函除外）。
- **有温度**：“目中有人”。写安全事故、灾害、群众诉求一类内容时，不能只见成绩、不见人。有地方在学生受伤事件发生后发文，通篇说“持续向好”，招致舆论批评，这就是教训。
- **整齐与参差**：
  - 对仗、排比是机关笔杆子的偏好，但物极必反。长短句、整句散句交替使用效果最好。
  - “金句”每段一两句足矣，用力过猛会以文害义。
- **有个性**：领导讲话要有本色，不千人一面。可以用比喻、故事和大白话把大道理讲明白，但故事必须真实。

### 常用词句
词句是工具，不是目的：每一句“套话”后面，都要跟上实打实的内容。

| 用途 | 常用词句 |
|---|---|
| 成效 | 更加（完善、巩固、优化、有力）；更趋（稳健、合理）；不断（增强、提升、深化）；持续（向好、改善）；明显（提升、好转、见效）；显著（增强、改观）；稳步（推进、提升）；加快（形成、构建）；取得（突破、实效、积极进展）；迈上新台阶；开创新局面；稳中有进；从无到有 |
| 措施领起 | 着力、全力、大力、持续、扎实、切实、狠抓、强化、坚持、聚焦、围绕、突出、紧扣、对标、坚定不移、千方百计；以……为抓手（突破口）；在……上下功夫；确保……落到实处 |
| 必要性 | 是……的必然要求（内在要求、迫切需要、重要保障、关键所在、应有之义）；事关……；对……具有重要意义；着力增强工作的政治性、战略性、前瞻性 |
| 问题 | 在肯定成绩的同时，也要清醒看到……；……还不够平衡、不够充分；……不到位、不规范、不协同、不健全等问题仍不同程度存在；与……的要求相比还有差距 |
| 抓落实 | 压实责任；细化举措；建立台账；明确时间表、路线图；清单管理；闭环销号；定期调度；督查通报；跟踪问效；以目标倒逼进度，以时间倒逼程序，以督查倒逼落实 |
| 保障 | 加强组织领导；强化统筹协调；加强资金保障；强化法治保障；加强督促检查；加强宣传引导；纳入绩效考核 |
| 结尾 | ……责任重大、使命光荣；以……的精神状态和务实作风，确保……落地见效；为……作出新的更大贡献 |

## 七、论证工具箱
适用于调研报告、政策建议、理论文章和涉外法治分析。

### 先判断，再下笔
1. **先辨真假**：
   - 找原始出处，如文件全文、裁判文书、外方官方文本；读原文，不读二手转述；读全文，不只读标题。
   - 多源交叉印证，单方说法慎用。
   - 排一条时间线，常能发现被忽略的关键细节。
2. **再辨是非**：合不合法，合不合理，合不合情——法、理、情逐层推进。不把法律问题与道德问题、政治问题混为一谈。
3. **后论好坏**：不违法、不违规就是“对”，但可能还“未到最好”。建设性意见就从这里提出。

### 分析工具
- **点—线—面**：从个案（点），到相关制度的演变脉络（线），再放到全面依法治国、高质量发展等大局中看（面）。熟悉制度演变和机构变迁，才不会误读政策信号。例如，废止一部早已失去上位法依据的旧规章，只是例行清理，不等于“放开”。
- **事实层与利害层**：
  - 先在事实层去伪存真。警惕“片面真实”：用部分事实拼出的假象。
  - 再在利害层分析：谁主张什么权利，是否损害他人的权利，市场能否解决，哪种方案社会成本最小。
  - 一句话概括：“让科学的归科学，产权的归产权。”
- **四象限**：按手段（私权利或公权力）和目标（私人利益或公共利益）交叉，分出四类：市场行为、公益慈善、正当的政府行为、寻租腐败。先定位，再选分析框架。
- **参照系**：找几个可比对象（他国、他省、历史时期、同类制度），比较所有异同。可比性是前提，不以今非古，不以己度人。
- **提取变量**：用几组变量组合出全部情形，讨论才完备，避免“一刀切”式结论。
- **对称性**：监管者、决策者也不是全知全能、大公无私的。警惕“出了事就呼吁加强监管、再立个法”——已有法律时，问题往往出在执行上；过度监管也有成本，要逐项评估必要性和实效。
- **看不见的部分**：评估政策时，既要看直接效果，也要看被挤出、被替代、本可发生却没有发生的东西（“破窗谬误”）。
- **文本比较**：把不同年份、不同层级文件里的同一表述放在一起比，提法的增删变化往往就是政策信号。但要结合制度演变来判断，防止过度解读。
- **陌生领域先补课**：查权威论文和研究报告；看各国、各地做法，并交叉验证；找历史参照；能请教专家的请教专家。不要写“万金油”式的外行话。
- **三种思维**：系统思维，从一张网看一个点；历史思维，以史为鉴要有可比性；批判思维，存在的未必合理，多想想处境不同的人会怎么看。

### 证据与论证
- **证据有强弱**：
  - 事实不等于证据，能直接推出结论的事实才是证据。
  - 一般而言，权威统计、正式文件、生效裁判和系统研究较强，典型案例次之，个人证言和极端个案最弱。
  - 不用孤例证明普遍问题；由个案推及群体，要加限定。
- **审视对方证据要像法庭质证**：
  - 来源和资质对不对口，时间和适用标准对不对得上，引文有没有断章取义。
  - 对方援引的条款如果只是宣示性的、没有罚则，恰好可以转为己方论据。
- **立论方法**：
  - 归纳：从个别到一般，要防“黑天鹅”。
  - 演绎：大前提必须成立。
  - 类比：同类相比。
  - 因果：多因多果，分清直接原因、间接原因和深层原因，不把时间先后当因果。
  - 举例：典型，有普遍性。
  - 比喻只能辅助论证，不能代替论证。
- **防六种逻辑错误**：以偏概全、假性因果、滑坡谬误（把可能串成必然）、以喻代证、偷换概念（包括“你讲法律，他谈政治”式的角度切换）、诉诸立场（上纲上线、诛心之论）。守住同一律、矛盾律、排中律。
- **诚实**：不因希望某事为真就相信它，也不因某个结论“有好处”就认定它对。把几种可能的结论按可能性排序，随新事实更新判断。
- **数据要看结构**：亮眼的总量和增速，可能掩盖结构性问题。纵向与历史比，横向与同类比。

### 呈现
- **研究做足，呈现做减法**：
  - 用最核心的数据和材料；假设读者知道基础事实，少讲铺垫，多讲判断。
  - 术语首次出现时要解释。
  - 核心论点可以在开头、中间、结尾以不同详略重复出现。
- **保持建设性**：溯缘由、解扣子、讲道理、释疑惑、献良策。对职能部门有礼有节、点到为止，留出改进空间。
- **写完做两次换位**：站在读者角度，被说服了吗？站在被批评对象的角度，服气吗，有没有受到无端伤害？
- **评论和理论文章**可以用五段结构：“叙（事实）—阐（观点）—引（引申提高）—议（正反例证）—结（对策）”。
- **自选题目**（理论文章、调研课题）看三点：公共性（关注面广），稀缺性（重要但少有人说透），匹配性（契合发表平台和自身专长）。
- **投稿文章**：先研究目标报刊已发表的同类文章，体例、篇幅和风格向它靠拢。可以先列出五到十个备选题目，再逐步聚焦到最新颖的立意。

## 八、涉外法治类材料
- **读原文**：
  - 外国法律、判决、制裁清单、国际组织文件、外方声明，都以原始文本为准，不依赖媒体转述。
  - 引用时注明全称、发布机构和日期，必要时括注外文原名。
  - 看原始名单、全文条款，常能发现与通行解读不同的事实，例如名单上还有哪些国家、条款有没有罚则、何时生效。
- **术语和名称要精确**：
  - 法律名称用全称或规范简称。
  - 外国机构、官员、职务用规范译名，并核对现任职务；机构已撤并的，加“原”字。
  - 条约、公约、协定、议定书、谅解备忘录、联合声明等文件性质不同，不能混用。
  - 分清国内法与国际法，分清立法、执法与司法，分清法律问题与政治问题。
  - 引用国内法依据时注意效力层级：宪法＞法律＞行政法规＞地方性法规和规章（地方性法规与各类规章之间的关系，依《立法法》判断）。新规定不得与上位法相抵触。
- **信源意识**：
  - 了解外国媒体的立场分野。不假设西方铁板一块，也不假设知名媒体必然客观。
  - 多方说法不一时，先找共同部分，再按可能性判断；必要时“让子弹飞一会儿”。
- **立场与口径**：
  - 对外表态和定性，以外交部等权威发布为准，不自创新提法。
  - 分析外方动向不一边倒：讲清双方的出发点、制度和利益考量，再提出建设性对策。态度是：中国立场，全球视野，建设性。
- **比较借鉴**：各国做法要交叉验证，找出对我们有用的“增量”。结合我国制度和国情，说明能不能借鉴、怎样借鉴，不机械照搬。

## 九、格式速查
需要输出 Word 文件或排版时，依据 GB/T 9704—2012《党政机关公文格式》：
- **纸张和标题**：用A4纸。标题用2号小标宋体，居中，可分行排成梯形或菱形，回行时保持词意完整。主送机关在标题下空一行，顶格，后加全角冒号。
- **正文**：3号仿宋体，每段首行空二字；每页22行，每行28字。
- **层次序数**：
  - 依次用“一、”“（一）”“1.”“（1）”。一般第一层用黑体，第二层用楷体，第三、四层用仿宋。
  - 通常标题独占一行时，末尾不加标点；与正文同段时，标题后加句号。
- **附件说明**：正文下空一行、左空二字，写“附件：”。多个附件用“1.”“2.”编号，附件名称后不加标点。
- **签发人和附注**：上行文（请示、报告）要标注签发人。附注加圆括号，居左空二字，编排在成文日期下一行。
- **日期和文号**：成文日期用阿拉伯数字写全年、月、日，月、日不编虚位（写2025年3月5日，不写03月05日）。发文字号的年份用六角括号，如〔2025〕。
- **标点**：中文用全角标点；阿拉伯数字和外文字母用半角。
- **数字**：
  - 统计数据用阿拉伯数字。
  - 概数和固定词语用汉字，如三四个、十几天、“十四五”规划。
  - 年份不简写。
  - 数值范围用“～”或“—”连接；百分数范围两个百分号都保留，如30%～50%。
- **引用公文**：按惯例先引标题，后引文号，如《关于××的通知》（×发〔2025〕×号）。
